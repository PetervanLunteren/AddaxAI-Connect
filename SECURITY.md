# Security policy

## Supported versions

Security fixes go into the latest release only. Run the latest release, see the [update guide](https://connect.addaxai.com/update-guide/).

## Reporting a security problem

Please do not open a public issue. Report it privately on the [Security tab](https://github.com/PetervanLunteren/AddaxAI-Connect/security) of this repository, with "Report a vulnerability", or email [peter@addaxdatascience.com](mailto:peter@addaxdatascience.com). The report stays private until a fix is out.

I reply as soon as I can. Keep in mind that this is a one-person project, so the reply is best effort.

How AddaxAI Connect is protected is on the [security](https://connect.addaxai.com/security/) page.
