# Two-factor login

Two-factor login adds a code from an authenticator app to your password.

## For every user

### Switch it on

Go to Account, behind the circle with your letter in the top right. The app walks you through it.

### Lost your phone

Log in with one of your recovery codes. No codes either? Ask a project admin or a server admin to reset your two-factor login.

## For project admins

### Make it mandatory for a project

In Project settings, switch on "Require two-factor login". Everyone who can open the project, server admins included, then has to set it up at their next login. Nobody is logged out.

### Reset it for a user

On the Users page, open the three-dot menu of the user and choose "Reset two-factor login". The user gets an email.

A project admin cannot reset a server admin, or a user who is also in a project they do not manage. A server admin can reset anyone but themselves. Locked out as the only server admin? See [operations](operations.md#common-issues).
